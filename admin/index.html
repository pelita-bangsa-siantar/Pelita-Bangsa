Cara menyiapkan folder

  1. Buat folder di Google Drive, upload foto kegiatan ke dalamnya.
  2. Klik kanan folder → Bagikan → akses umum Siapa saja yang memiliki link (Pelihat).
  3. Salin link folder, tempel di formulir, lalu simpan.

Foto diurutkan menurut nama file; foto pertama menjadi sampul. Setelah menambah foto ke folder, klik tombol sync pada album agar web membaca ulang.
